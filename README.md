# Smart Data Analyzer

## Overview
Smart Data Analyzer is a Python project that analyzes numerical data and transforms it into meaningful insights.

## Features
- Calculate averages
- Find highest and lowest values
- Count records
- Visualize data with charts

## Technologies Used
- Python
- Statistics
- Matplotlib

## Example Data

85, 92, 78, 96, 88, 74, 91, 82

## Results

- Average Grade: 85.75
- Highest Grade: 96
- Lowest Grade: 74
- Number of Grades: 8

- CSV file support
